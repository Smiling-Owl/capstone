# Verbatim Quotes / Key Claims
* "There is currently no single, publicly accessible 'NDRRMC API' designed for LGUs to directly push their Situation Reports (SitReps) into the national database."
* "LGUs are required to use standardized reporting templates (typically in DOCX or PDF format) provided by the OCD to ensure data consistency."

# Relation to Hypothesis
Refutes Hypothesis 1. Direct API integration is not standard or feasible for generic LGU software. The system MUST focus on generating standardized PDF/DOCX templates instead.
